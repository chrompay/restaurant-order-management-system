# Changelog

All notable changes to the Restaurant Order Management API are
documented here.

The project generally follows semantic versioning as it evolves.

------------------------------------------------------------------------

## \[0.8.0\] - Current

### Added

-   Pagination for foods
-   Pagination for orders
-   Search by food name
-   Order filtering by status
-   Sorting for foods and orders

### Improved

-   Standard pagination metadata
-   Controller consistency
